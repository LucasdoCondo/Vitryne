# Vitryne Quick Links

Extensão local de acesso rápido a portais oficiais. Ela apenas abre os endereços definidos no popup em uma nova aba.

## Instalação local no Chrome ou Edge

1. Abra `chrome://extensions` (ou `edge://extensions`).
2. Ative **Modo do desenvolvedor**.
3. Clique em **Carregar sem compactação**.
4. Selecione a pasta `extension` deste repositório.

## Privacidade e limites

- Não solicita permissões de cookies, armazenamento, abas ou acesso a sites.
- Não lê, guarda nem transmite senhas, cookies, tokens, `localStorage` ou dados de navegação.
- Não detecta se uma conta está conectada. O usuário faz login diretamente no site oficial.
- Não sincroniza sessões com a API do Vitryne e não automatiza ações nos marketplaces ou redes sociais.
- Os dados de login e o estado de sessão permanecem sob controle do navegador e dos sites oficiais.

Esta extensão é apenas um lançador de páginas. Para integrações automáticas de publicação ou links de afiliado, use APIs oficiais e permissões concedidas pelas plataformas.
